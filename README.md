# Welcome to GameCampus 👋
![Version](https://img.shields.io/badge/version-0.1.0-blue.svg?cacheSeconds=2592000)

> GameCampus is developing an ambitious epic fantasy video game, and this project is part of that vision — a visually stunning and interactive web application that allows users to create and customize their own fantasy characters, inspired by the Dungeons & Dragons universe.

### 🏠 [Homepage](https://game-campus.vercel.app/)

## 📦 Tech Stack

- **Framework**: Next.js 15
- **UI**: React 19, Tailwind CSS 4
- **Icons**: react-icons
- **Modals & Alerts**: SweetAlert2
- **Authentication**: jsonwebtoken, jwt-decode, bcryptjs
- **Linting**: ESLint + eslint-config-next

## 📥 Install

```sh
git clone https://github.com/joanomana/Proyecto_JavaScript_Oma-aJoan.git
npm install
```

## 🔧  Usage

```sh
npm run dev
```
Then open your browser and go to http://localhost:3000

## 🌐  D&D 5e API

This project uses the [The 5th Edition Dungeons and Dragons API](https://www.dnd5eapi.co/) to fetch data about dungeons & dragons:

- Race
- Class
- Type armor and armors
- Type weapon and weapons
- Special abilities
- Features
- Accessories
